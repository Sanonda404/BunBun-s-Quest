# Learner Profile

## Initial Idea
A cozy, calm desktop companion app that helps users stay focused while studying. It intelligently distinguishes between useful study-related web searches and irrelevant distractions, avoiding unnecessary blocks. For breaks, it provides a curated feed of engaging, educational content (like history shorts/reels) matching the user's interests rather than mindless scrolling.

## Demonstrated Technical and Agent Experience
New to coding and AI coding agents.
Evidence: "I don't have much experience, you have to teach me"

## Planning-Workflow Experience
New to plan-first / spec-driven development.
Evidence: Expressed needing guidance from scratch.

## Desired Learning Outcome
Understanding how to work effectively with an AI coding agent.
